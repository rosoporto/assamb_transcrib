# assemblyai-cli — транскрибатор на AssemblyAI

Один вход: ссылка или файл. Дальше всё само — скачать звук (если это YouTube), отправить в AssemblyAI,
положить рядом готовый `.txt` с таймкодами.

```bash
uv run transcrib "https://www.youtube.com/watch?v=..."
uv run transcrib ./записи/встреча.mp4
uv run transcrib ./записи              # все подходящие файлы папки
```

Пример результата:

```
[00:00:00] Первый абзац распознанного текста. Он начинается с таймкода и заканчивается
на границе предложения или после паузы в речи.

[00:00:17] Следующий абзац идёт с новым таймкодом. С опцией --speakers в начале абзаца
добавляется метка вроде «Спикер A:».
```

## Для пользователя

### Что нужно
- Python 3.10+ и [uv](https://docs.astral.sh/uv/) (`pip install uv` или установщик с сайта).
- Интернет и аккаунт AssemblyAI. **Распознавание платное, списывается с вашего аккаунта.**
- `ffmpeg` не нужен: файлы уходят как есть, звук из YouTube скачивается готовым аудиопотоком.

### Установка
```bash
git clone git@github.com:rosoporto/assamb_transcrib.git
cd assamb_transcrib
uv sync
cp .env.example .env        # затем впишите свой ключ
```
Ключ берётся на https://www.assemblyai.com/dashboard. Положить его можно тремя способами — программа
ищет по порядку:

1. переменная окружения `ASSEMBLYAI_API_KEY`;
2. `.env` **в текущей папке** (там, откуда вы запускаете команду);
3. `.env` рядом с `main.py`.

Проверка ключа (бесплатный запрос):
```bash
uv run transcrib key
```
Ожидаемый ответ: `API-ключ принят.`

Запуск из любой папки — либо через `uv`:
```bash
uv run --project ~/assamb_transcrib transcrib "ссылка"
```
либо алиасом:
```bash
alias transcrib='uv run --project ~/assamb_transcrib transcrib'
```

### Что происходит по команде
1. Ссылка → yt-dlp качает звук во временную папку (плейлисты и текущие эфиры отклоняются).
2. Файл уходит в AssemblyAI, создаётся задание; id пишется в журнал.
3. Готовый текст атомарно пишется в `./ГОТОВЫЕ_ТЕКСТЫ/<имя>.txt` (папку можно задать через `-o`).
4. Временный звук удаляется. Исходные файлы не изменяются и не удаляются.

Уже готовые тексты пропускаются без повторной оплаты — чтобы обработать заново, добавьте `--force`.

### Команды
| Команда | Что делает |
|---|---|
| `transcrib <ссылка\|путь>` | короткая форма: ссылка → YouTube, путь → файл или папка |
| `transcrib run <ссылка\|путь>` | то же самое явно |
| `transcrib file <путь>` | только файл или папка |
| `transcrib youtube <ссылка>` | только YouTube |
| `transcrib key` | проверить ключ |

### Опции (общие)
| Опция | Что делает |
|---|---|
| `-o, --output-dir ПАПКА` | куда класть `.txt` (по умолчанию `./ГОТОВЫЕ_ТЕКСТЫ`) |
| `-l, --language КОД` | `auto` (по умолчанию, автоопределение) или `ru`, `en`, … |
| `--speakers` | метки спикеров: `[00:01:10] Спикер A: …` |
| `-t, --terms "А,Б,В"` | свой список терминов (`"ChatGPT,Claude Code"`), +$0.05/ч |
| `--with-terms` | включить вшитый список терминов, +$0.05/ч |
| `--no-terms` | принудительно без терминов (перекрывает `.env`) |
| `--force` | перезаписать уже готовый `.txt` |
| `-y, --yes` | не спрашивать подтверждение для папки с несколькими файлами |
| `--dry-run` | показать план и цену, ничего не скачивая и не оплачивая |

### Термины: вшиты, но по умолчанию ВЫКЛЮЧЕНЫ
В `main.py` есть вшитый список `DEFAULT_TERMS` (ChatGPT, OpenAI, Anthropic, Claude Code, Codex, OpenCode,
Gemini, GitHub, Python, Docker и т. п.), который уходит в AssemblyAI как `keyterms_prompt`. Это платная
надбавка **+$0.05/ч**. По умолчанию подсказка **не отправляется**: на двух проверочных роликах (60 с и 12,4 мин,
русский, `model=universal-2`) тексты с терминами и без них **совпали слово в слово**. Возможно, подсказка
работает только на `universal-3-5-pro`, а сервис отвечает `universal-2` (не выяснено).

| Что нужно | Как |
|---|---|
| Без терминов (по умолчанию) | ничего не делать |
| Вшитый список на один запуск | `--with-terms` |
| Свой список на один запуск | `--terms "Термин1,Термин2"` (замещает вшитый) |
| Вшитый список навсегда | в `.env`: `ASSEMBLYAI_TERMS=default` |
| Свой список навсегда | в `.env`: `ASSEMBLYAI_TERMS=Термин1,Термин2` |
| Принудительно выключить (перекрывает `.env`) | `--no-terms` |
| Изменить вшитый список | правка `DEFAULT_TERMS` в `main.py` |

Приоритет: `--no-terms` → `--terms` → `--with-terms` → `ASSEMBLYAI_TERMS` → выключено.
Решающим для качества оказался **звук**: при ~49–64 кбит/с получалось «ChatterJPT», при ~130 кбит/с —
«ChatGPT». Поэтому yt-dlp берёт `bestaudio`; размер файла на цену не влияет.

Форматы: `mp3 mp4 m4a mov mkv avi webm wav aac flac ogg opus mpeg mpg`.
Если в папке есть файлы с одинаковым именем и разными расширениями (`урок.mp3` и `урок.mp4`),
результаты получат суффикс: `урок_mp3.txt`, `урок_mp4.txt`; при полном совпадении имени добавится `_2`.

Проверить план, ничего не оплачивая:
```bash
uv run transcrib "ссылка" --dry-run
```
Покажет название, длительность, имя файла и цену; для папки — список файлов и что будет пропущено
(уже готовые `.txt`). Ключ для `--dry-run` не нужен.

### Сколько это стоит
Перед скачиванием и после каждой обработки печатается оценка:

```
Цена: 13.1 мин ≈ $0.0458 (оценка: $0.21/ч)
Потрачено: 4.7 мин ≈ $0.0118 (оценка: $0.21/ч)
```

Считается по тарифу AssemblyAI: **Universal-3.5 Pro $0.21/ч** (модель по умолчанию), плюс
**$0.02/ч** за спикеров (`--speakers`), плюс **$0.05/ч** за термины (по умолчанию выключены; `--terms`, `--with-terms`).
**Это оценка, а не данные из сервиса:** API стоимость не возвращает, программа умножает длительность
на тариф и пишет в журнал фактически использованную модель (`model=universal-3-5-pro`).
Точный остаток и реальные списания — только в дашборде AssemblyAI.
Тариф можно переопределить в `.env` (см. `.env.example`), но сверяйте с
https://www.assemblyai.com/pricing: цены меняются.

### Если что-то не так
| Симптом | Что делать |
|---|---|
| `Ключ не найден` | нет `.env` (проверьте, что он в текущей папке) или пустая строка ключа |
| `AssemblyAI отклонил ключ` | скопируйте ключ из дашборда целиком, проверьте `transcrib key` |
| `Связь прервалась… Повтор через N с` | норма: загрузка повторяется до 3 раз, опрос статуса — до 5 |
| `Не удалось скачать звук` | сеть или ограничение YouTube; повторите позже либо скачайте файл вручную и передайте путь |
| `Ошибка: … пустую транскрибацию` | в файле нет речи (тишина/музыка) |
| В тексте перепутаны термины | проверьте качество звука; термины можно включить (`--with-terms`), но пользы не доказано, см. раздел «Термины» |
| YouTube: 429 / «подтвердите, что вы не бот» | подождите, смените сеть/ссылку; приватные ролики недоступны |

Журнал: `ГОТОВЫЕ_ТЕКСТЫ/transcription.log` рядом с результатами (больше 2 МБ — старая часть уходит
в `transcription.log.1`). Формат — одна строка на событие: время, событие, файл, id задания, секунды,
оценка стоимости, язык, модель. Ключ в журнал и сообщения об ошибках не попадает.

Коды возврата: `0` — всё хорошо, `1` — были ошибки, `2` — неверная настройка (ключ, формат, путь),
`130` — остановлено Ctrl+C (готовые тексты сохраняются).

## Для разработчика

### Структура
```
main.py            весь код (Typer-приложение, точка входа transcrib)
tests/test_main.py базовые юнит-тесты (форматирование, имена, журнал)
tests/test_cli.py  единый вход, тарифы, классификация ретраев
pyproject.toml     зависимости, [project.scripts], настройки ruff/pytest
.env / .env.example
```

### Поток обработки (`transcribe_one`)
1. `upload_with_retries` → `upload_file`: загрузка **напрямую через httpx** на
   `POST {base_url}/v2/upload` с явным `Content-Length` (до 3 попыток).
2. `transcriber.submit(upload_url, config)` — создаётся платное задание, id пишется в лог (`SUBMITTED`).
3. `wait_with_retries` → `transcript.wait_for_completion(poll_timeout=3 ч)`; при сбое сети опрос
   продолжается **по тому же заданию** (до 5 раз) — повтор не создаёт дубль.
4. `format_transcript` собирает абзацы по словам с таймкодами и атомарно пишет `.txt` (`*.part` → rename).
5. Возвращаются секунды аудио (`audio_duration`) для расчёта стоимости.

Ретраится только загрузка и опрос, но **не** `submit`: повтор создания задания мог бы
оплатить распознавание дважды. Повторяются только временные ошибки (сеть, таймауты, 429, 5xx);
401/403/404 и прочие 4xx сразу уходят наверх с понятным сообщением.

### Решения и грабли
- **Своя загрузка вместо `Transcriber.upload_file` из SDK.** Встроенная на этой сети зависла на
  15 МБ с `The write operation timed out`. Подмена на httpx с `Content-Length` работает.
- **`aai.settings.base_url` без `/v2`.** Путь загрузки строится как `{base_url}/v2/upload`.
- **SDK 1.x** (`assemblyai>=1.10,<2`): `TranscriptionConfig(language_detection=True | language_code=…,
  speaker_labels=…, keyterms_prompt=[…], speech_models=[…])`.
- **Модель задаётся явно** (`speech_models=["universal-3-5-pro", "universal-2"]`), иначе цена и качество
  зависят от серверного значения по умолчанию. Фактическая модель пишется в журнал.
- **Стоимость оценочная** и учитывает надбавки за спикеров и термины; API её не возвращает.
- **Абзацы:** новый абзац при паузе ≥ 1,8 с (`PAUSE_MS`), смене спикера, либо на конце предложения
  при ≥ 40 слов или ≥ 30 с; жёсткий предел 100 слов.
- **Имена файлов:** `safe_name` убирает эмодзи и запрещённые символы, обрезает до 180 знаков и
  экранирует зарезервированные имена Windows (`CON`, `NUL`, …). `output_names` гарантирует уникальность
  без учёта регистра.
- **Секреты:** `scrub()` вырезает ключ из логов и ошибок, `err()` дополнительно экранирует
  rich-разметку — имена файлов и заголовки выводятся через `escape()`.
- **Журнал не влияет на работу:** любая ошибка записи глотается, строка всегда однострочная.
- **Единый вход:** `prepare_argv` подставляет `run`, если первый аргумент не команда; поэтому работает
  и `transcrib <ссылка>`, и `transcrib -o папка <ссылка>`.

### Известные ограничения
- Файл грузится одним запросом (потоково, без загрузки в RAM, но без докачки при обрыве).
- Нет параллельной обработки файлов (идут по очереди) и докачки частичных результатов.
- YouTube: одно видео за вызов, звук проходит через диск (временная папка), а не через RAM.
- Скачивание с YouTube зависит от сети и ограничений платформы: при блокировке CDN поможет смена сети
  или ручная загрузка файла.
- Журнал хранит текущий файл и одну архивную копию (`.log.1`).

### CI
`.github/workflows/ci.yml` — на каждый push и pull request: `ruff` и `pytest` на Ubuntu и Windows,
Python 3.10 и 3.13. `uv sync` в том же прогоне собирает пакет, то есть заодно проверяет
`pyproject.toml` и команду `transcrib`.

### Как расширять
- Новая опция распознавания: параметр в `make_transcriber` → `aai.TranscriptionConfig(...)`.
- Другой формат вывода (`.srt/.vtt`): слова с `start/end` в мс уже есть в `transcript.words`,
  нужен новый форматтер рядом с `format_transcript`.
